Comparator vs Field Scorer

A complete operational explanation of how both engines evaluate each company field, step by step, using whitestudiolondon.com as a live reference.

Core Purpose: The Field Scorer provides a clean, independent 0–100 mathematical business score for every field. The Comparator performs deep technical checks, corroborating signals across multiple pages to reject scraping artifacts and noise. Both run together to output a single unified verdict.

Field Scorer Independent Math

What it is: A pure 1-to-1 evaluator. It takes the previous DB baseline value and compares it solely to the crawled value of the same field.

  • No cross-field noise: Never checks secondary fields or outside tags.
  • Deterministic Points: Assigns scores (0 to 25 pts) based on exact string match, Levenshtein/Jaccard similarity, or absence.
  • Unchanged Guarantee: If a field is identical, it always yields 0 pts with status UNCHANGED.

Comparator Engine Deep Corroboration

What it is: A forensic validator. It checks whether a detected field difference is real, corroborated by other pages, or just scraping noise.

  • Cross-field validation: Validates brand from title, copyright, and Clearbit.
  • Noise Guards: Caps uncorroborated rewrites at log_only if the underlying page content didn't change.
  • Baseline Quality Detection: Flags when the DB baseline was missing pages or links.

  • Reads old.companyName ("White Studio") and new.companyName (null).
  • Checks if both are non-empty. Since new.companyName is null, direct match fails.
  • Detects that the company name was previously known but missing in the live crawl.
  • Assigns 10 points change penalty with status NOT_FOUND_IN_CRAWL.

Comparator Operation

  • Inspects fallback signals: nameFromCopyright, nameFromTitle, clearbitName.
  • Discovers nameFromCopyright: "White Studio" in the crawl footer.
  • Determines that the company did NOT rebrand (it's still White Studio), but the crawler's heuristic merely failed to set the top-level name header.
  • Labels it [NOT_FOUND] and suppresses high-priority rebrand alert.
Dependent Verdict: [NOT_FOUND] Rebrand alert avoided (footer copyright matches)
description (Max Weight: 20 pts)
MAJOR_CHANGE Score: 20 / 20

Field Scorer Operation

  • Tokenizes old description (662 chars) and new description (353 chars) into unique words.
  • Calculates Jaccard word-overlap similarity: (Intersection / Union) = 19% similarity.
  • Applies threshold: similarity < 45% triggers MAJOR_CHANGE.
  • Assigns max weight: 20 points.
Independent Verdict: Substantially rewritten (19% similarity) (+20 pts)

Comparator Operation

  • Applies Non-Circular Corroboration Rule: a description change is only trusted if corroborated by a thematic change in homeContent or commercial links.
  • Compares homeContent: detects the homepage body text is 100% identical.
  • Concludes the change is purely meta-tag restyling, not a company pivot.
  • Downgrades priority tier to [LOG_ONLY] (reason: baseline_stale_meta).
Dependent Verdict: [LOG_ONLY] Uncorroborated by homepage body
